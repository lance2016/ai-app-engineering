> 一句话：这课解决什么问题。

## 本课怎么学

- **📖 阅读模式**：心智模型 → 核心机制 → 常见失败 → 生产方案 → 框架映射 → 真实项目。
- **🛠 实战模式**：code → failure injection → exercises → project milestone → tests。

两种模式可以切换；练习是加深理解和留下验收证据的工具，不是阅读下一节的门槛。
