# Capstone 4 Multi-tenant AI Platform

> M6 是这个 Capstone 的设计阶段：一份多租户知识库与任务 Agent 平台的 RFC。这里再往前走一步，把 RFC 里最关键的一个切片实现出来，让威胁模型里的每条防线都有测试。

## 需求

- 沿用 M6 的 RFC，补一个实现切片：租户隔离、配额与限流、按租户成本账、Skill 与 MCP Server 的白名单注册表、管理 API
- 威胁模型里的每条威胁对应一个代码级防线和一个测试
