# Capstone 2 RAG + Memory Agent

> M4 用示例语料把管线跑通。这个 Capstone 换成你自己选的真实语料，把引用、版本、删除、记忆和评测全部做到能对外解释的程度。

## 需求

- 自选一个领域语料（至少 200 份文档），支持更新与删除
- 每个回答带可回链到原文位置的引用
- 记忆只存已确认的用户偏好与事实，每条带来源，可查可删
- 50 条以上评测集，Recall@k 与回答正确率有基线
